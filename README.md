# 7942 친구사이

학생이 4자리 코드로 들어와 직접 답하는 교우관계 설문 프로그램입니다.
화면과 분석은 이 저장소(GitHub Pages)에서 열리고, 학생 응답은 **각 선생님의 구글 시트에만** 저장됩니다.

- 학생 화면: https://musicalpe.github.io/7942/
- 선생님 화면: https://musicalpe.github.io/7942/teacher.html
- 미리보기(지어낸 이름): https://musicalpe.github.io/7942/teacher.html?demo , https://musicalpe.github.io/7942/?demo

## 할 수 있는 것

- 학생: 서술형 질문, 친구마다 ○ △ X 표시, 칭찬하고 싶은 친구와 이유, 사이가 좋지 않은 친구(비워도 됨), 선생님께 한마디
- 관계표: 서로 ○(초록)·서로 X(빨강)·엇갈림(노랑), 관심도·호감도·긍정성·부정성 자동 계산
- 친구 그룹: 서로 ○를 누른 학생끼리 자동으로 묶고, 그룹 사이 갈등과 관계 그림을 보여 줌
- 학생별 보기, 서술형 모아 보기, 회차 비교(지난 설문과 달라진 점)
- 설문 설정: 질문, 칭찬 친구 고르는 방식(남녀 나눠 몇 명 / 성별 상관없이 몇 명 / 묻지 않기) 등
- 친구 관계 표시는 3단계(○ △ X) 또는 5단계 척도 중에서 회차마다 고를 수 있음
- AI 분석(학급 전체·학생 한 명): 학생 이름은 번호로 바꿔서 보내고, 결과만 선생님 화면에서 다시 이름으로 보여 줌
- 선생님 화면은 [앱으로 설치]를 누르면 컴퓨터·휴대폰에 앱처럼 설치됨

소개 그림 20장: [intro](intro/) 폴더 (01.png ~ 20.png)

## 처음 설치 (선생님 한 번만)

1. 껍데기 시트 사본 만들기: https://docs.google.com/spreadsheets/d/1x-yX5q_4KDUINBTxxXw7Oc7cbsWddgakaVzgkcQiaFs/copy
   열리면 [사본 만들기]를 누릅니다. (껍데기 코드가 이미 들어 있어요)
2. 내 사본에서 [확장 프로그램] > [Apps Script]를 엽니다.
3. 먼저 권한 받기: Apps Script 위쪽 함수 목록에서 `start`를 고르고 [실행]을 누릅니다. 권한 창이 뜨면 계정을 고르고, "Google에서 확인하지 않은 앱" 화면이 나오면 [고급] > [(프로젝트 이름)(으)로 이동] > [허용]을 누릅니다. 내 시트에만 쓰는 코드라 괜찮아요.
   - "액세스 차단됨: 승인 오류 / The OAuth client is not fully created yet" 이 나오면 사본을 막 만들어 구글 쪽 준비가 덜 된 거예요. 5~10분 기다렸다가 다시 실행하면 됩니다.
4. 오른쪽 위 [배포] > [새 배포] > 톱니바퀴에서 유형 [웹 앱]
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 나온 웹 앱 주소(…/exec)를 누르면 7942 선생님 화면으로 넘어가면서 이 시트와 자동으로 연결됩니다. (넘어가지 않으면 주소를 복사해 선생님 화면 첫 칸에 붙여 넣으세요)
6. 처음 비밀번호는 `0000` 입니다. [설문 설정] 탭에서 꼭 바꿔 주세요.

사본 링크가 안 열리면 새 스프레드시트를 만들고 [Apps Script]에 [shell/Code.gs](shell/Code.gs) 내용을 붙여 넣은 뒤 3번부터 하면 됩니다.

학교 구글 계정(업무용 도메인)은 "모든 사용자"로 배포가 막혀 있을 수 있어요. 그럴 땐 개인 구글 계정으로 만들어 주세요.

## 쓰는 순서

1. [학생 명단·코드]에서 명단을 넣고 저장하면 학생마다 4자리 코드가 생깁니다. 코드 카드를 인쇄해 나눠 줍니다.
2. [새 회차 만들기]를 누르면 설문이 열립니다.
3. 위의 [학생용 주소]를 누르고 둘 중 편한 방법으로 학생을 들어오게 합니다. 한 번 들어온 기기는 다음부터 7942 주소만 열어도 우리 반으로 들어옵니다.
   - 반 코드: [반 코드 만들기]를 누르면 5자리 숫자가 생깁니다. 안내장에는 `musicalpe.github.io/7942  반 코드 12345` 처럼만 적으면 됩니다.
   - QR · 긴 주소: 화면에 띄우거나 메시지로 보낼 때 편합니다.
4. 다 끝나면 [마감하기]를 누릅니다.

## 개인정보

- 이 저장소에는 화면 코드만 있고, 학생 자료는 전혀 올라오지 않습니다.
- 학생 응답은 선생님 시트에만 저장되고, 웹 앱이 선생님 권한으로 돌아가므로 학생은 시트를 볼 수 없습니다.
- 시트를 다른 사람과 공유하지 마세요. 친구에 대한 X 표시와 이유는 아주 민감한 내용입니다.

## 반 코드 등록소 (만든이용)

반 코드는 [registry/Code.gs](registry/Code.gs)를 붙인 시트 하나가 "반 코드 ↔ 각 반 껍데기 주소"만 기억하는 방식입니다. 학생 이름이나 응답은 저장하지 않습니다.
등록소 웹 앱 주소는 [config.js](config.js)의 `REGISTRY_URL`에 적습니다. 비워 두면 반 코드 기능이 숨겨지고, QR·긴 주소만 쓰입니다.

## 업데이트

화면과 분석 기능은 이 저장소가 바뀌면 자동으로 최신판이 열립니다.
