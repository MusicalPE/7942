7942 올리기 전 시험

1. 단순 수정 (글귀, 색, 여백, 그림 교체)  →  코드 검사만
     python3 tests/check.py
   문법과 따옴표·괄호 짝, 없는 함수 부르기, 단추가 가리키는 id, 판 번호가 파일마다 같은지를 봐요.

2. 기능 수정 (새 기능, 화면 배치 변경, 서버·저장 방식 수정), 또는 애매할 때  →  전체 시험
     bash tests/full.sh
   코드 검사에 더해 화면을 실제로 띄워서 로그인, 학생 제출과 시트 저장, 모든 탭, 짝·모둠 추천,
   AI(가짜 답), 강점 카드 링크를 한 번씩 밟아 봐요. 3~4분 걸려요.

하나라도 걸리면 올리지 말고 먼저 고쳐요. 올린 뒤에는 어떤 시험을 돌렸고 결과가 어땠는지 한 줄로 알려요.

필요한 것: python3 + playwright(크로미움), node. 검사 도구(eslint)는 처음 돌릴 때 저절로 받아 와요.
시험에 나오는 이름은 모두 지어낸 이름이고, 구글 시트는 gasmock.js 가 흉내 내요(진짜 시트에는 접속하지 않아요).
